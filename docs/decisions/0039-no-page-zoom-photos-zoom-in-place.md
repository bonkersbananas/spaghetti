# 0039. No page zoom on touch screens; photos zoom in place; text follows the person's size setting

Status: Accepted

**Decision:** On touch screens (`pointer: coarse`) the page can't be pinch-zoomed or double-tap-zoomed, in the installed app and in a browser tab alike. A photo in the viewer zooms in place instead (pinch, pan, double tap). Text follows the phone's text-size setting where the platform offers it. Mouse and trackpad keep the browser's zoom.

**Why:** Carl Oscar (Nov 12): zoom makes the installed app feel like a web page. Four layers, because no single one works everywhere: the viewport meta (`maximum-scale=1, user-scalable=no`) is honoured by Chrome on Android; `touch-action: pan-x pan-y` on `<html>` (app.css) takes pinch and double-tap zoom away in every engine that has `touch-action`, iOS 13+ included; `gesturestart`/`gesturechange` `preventDefault` (lib/no-page-zoom.ts) covers WebKit's own gesture events; and fields are at least 16 px, so iOS never zooms into a focused one (checked in `e2e/screens.spec.ts`). iOS Safari has ignored `user-scalable` and `maximum-scale` since iOS 10, deliberately, for accessibility ([WebKit: New Interaction Behaviors in iOS 10](https://webkit.org/?p=7367)), so in a tab on iPhone the meta tag alone does nothing; whether `touch-action` and the gesture events fully hold in the Home Screen app is something only a real iPhone confirms.

**Consequences:** Someone who relied on page zoom for small text loses it. What replaces it: the layout is in `rem` throughout (Android's font size and browser text settings scale it); on iOS the root size follows Dynamic Type through `-apple-system-body` (never below the design size, at most 125 %, re-read when the app comes back to the front); photos zoom up to 5×; the 3D view has its own pinch. The browser tab is covered too, not only the installed app, because a half-zoomable app is worse than either, and WebKit ignores the tab case anyway; if that proves unkind on Android, scope the rule to `display-mode: standalone`. Pull-to-go-back (0039's neighbour, `lib/pull-to-go.ts`) no longer allows `pinch-zoom` in its `touch-action`; a second finger always ends its chance.
